УИТСТОН · ГРОНСФЕЛЬД — WINDOWS НҰСҚАСЫ

Бұл — жергілікті HTML қосымшасын Microsoft Edge немесе Google Chrome арқылы
жеке терезеде ашатын шағын қаптама. Бұл жеке орындалатын .exe бағдарламасы емес.
Қосымшамен жұмыс істеу үшін интернет қажет емес. Ноутбукта Microsoft Edge немесе
Google Chrome және Windows PowerShell болуы керек. Скрипттер ештеңе жүктемейді.

ЖЫЛДАМ АШУ
1. ZIP мұрағатын толық шығарыңыз: «Барлығын шығару» / «Извлечь всё».
2. Wheatstone-Gronsfeld бумасын ашыңыз.
3. Open.cmd файлын екі рет басыңыз. Қосымша браузердің жеке терезесінде ашылады.
   Қысқа уақытқа консоль терезесі көрінуі қалыпты.

ОРНАТУ
1. Алдымен ZIP мұрағатын толық шығарыңыз.
2. Install.cmd файлын екі рет басыңыз. Әкімші ретінде іске қосу қажет емес.
3. Орнату аяқталған соң жұмыс үстеліндегі немесе «Бастау» мәзіріндегі
   Wheatstone-Gronsfeld таңбашасын ашыңыз.
4. Орнатылған файлдар тек ағымдағы пайдаланушының
   %LOCALAPPDATA%\WheatstoneGronsfeld бумасына көшіріледі.
   Қосымша екі аттас таңбаша жасайды: жұмыс үстелі және «Бастау» мәзірі.
5. Орнатқаннан кейін ZIP пен бастапқы шығарылған буманы өшіруге болады.

ҚОЛДАНУ
— Уитстон немесе Гронсфельд шифрын таңдаңыз.
— Мәтін мен кілтті енгізіп, шифрлауды немесе кері шифрлауды орындаңыз.
— Қазақ, орыс немесе ағылшын әліпбиін таңдауға болады.
— «Толық» батырмасы қадамдық есепті көрсетеді.
— Мәтін мен кілттер жабылғаннан кейін сақталмайды.
— Интернеттегі Sites нұсқасына кіру қажет емес; бұл көшірме толығымен жергілікті.

ӨШІРУ
1. Қосымша терезесін жабыңыз.
2. Win+R пернелерін басып, %LOCALAPPDATA%\WheatstoneGronsfeld енгізіңіз.
3. Ашылған бумадан Uninstall.cmd файлын екі рет басыңыз.
   Орнатылған қосымша бумасы және оның екі таңбашасы өшіріледі.
   ZIP мұрағаты мен бастапқы шығарылған бума өшірілмейді.
4. Портативті нұсқаны ғана қолдансаңыз, шығарылған буманы өшіру жеткілікті.

ЕСКЕРТУ
Бұл оқу мен модельдеуге арналған классикалық шифрлар қосымшасы.
Windows жүйесінде скрипттерді орындау ұйым саясаты арқылы шектелуі мүмкін.
Скрипттер әкімші құқығын сұрамайды және орындау саясатын өзгертпейді.
